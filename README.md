# VISUS
Embedded assistance system for visually impaired people using IR proximity sensors and real-time alert generation..


## Features

- Real-time obstacle detection
- Embedded alert generation
- Proximity sensing
- Portable assistance system
- Sensor integration
- Low-latency processing


## Technologies Used

- C++
- Microcontroller.
- Embedded Systems
- IR Sensors
- Real-Time Processing
- Sensor Integration

## Hardware Components

- ESP32-C3
- IR proximity sensors
- Buzzer / vibration module
- Portable 3.7v 1200Mah power supply
- TP4056 battery recharger
- VL53L0X sensors
- Boost Converter
